# Pre-Start Checklist - Before Building the App

## ✅ Cursor Settings to Configure

### 1. Documentation (Docs) - **DO THIS FIRST**
Go to: Cursor Settings (Ctrl+,) → Features → Docs → Add Documentation

**Add these 3 essential docs:**
- ✅ React Native: `https://reactnative.dev/docs/getting-started`
- ✅ Expo: `https://docs.expo.dev/`
- ✅ React Navigation: `https://reactnavigation.org/docs/getting-started`

**Add later when needed:**
- Supabase: `https://supabase.com/docs` (when setting up backend)
- Pokémon TCG API: `https://docs.pokemontcg.io/` (when integrating API)

### 2. Code Completion Settings (Optional but Recommended)
Go to: Cursor Settings → Editor → Code Completion

**Recommended settings:**
- ✅ Enable "Autocomplete" (should be on by default)
- ✅ Enable "Inline Suggestions" (helpful for beginners)
- ✅ Set "Suggestion Delay" to 100-200ms (faster suggestions)

### 3. File Exclusions (Recommended)
Go to: Cursor Settings → Features → Files

**Files/folders to exclude from indexing:**
- `node_modules/` (already excluded by default)
- `.expo/` (Expo build cache)
- `dist/` or `build/` (build outputs)
- `.env` (sensitive data - already excluded)

**Note:** These are usually auto-excluded, but verify they're there.

### 4. Git Settings (If Using Git)
Go to: Cursor Settings → Git

**Recommended:**
- ✅ Enable "Auto Fetch" (keeps Git updated)
- ✅ Enable "Enable Git" (if you want version control)

**Note:** Git is optional for beginners, but recommended for safety.

## ✅ Project Files Created

The following essential files have been created for you:

1. ✅ `.gitignore` - Excludes unnecessary files from Git
2. ✅ `.env.example` - Template for environment variables
3. ✅ `.cursorignore` - Excludes files from Cursor AI indexing

## ✅ Before You Start Building

### Step 1: Add Docs to Cursor (5 minutes)
- Open Cursor Settings

- This helps AI give you better code

### Step 2: Review the Rules Files (Optional)
- `USER_RULES.md` - How AI should behave
- `PROJECT_RULES.md` - Technical standards
- `PROJECT_COMMANDS.md` - Commands reference
- `USER_COMMANDS.md` - Your quick reference guide

- **Supabase account** (free): https://supabase.com
